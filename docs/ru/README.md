## Мессенджер одуванчик

### 📝 Описание проекта
Клиент-серверное приложение-мессенджер. Разработано в **учебных целях** и для пополнения **портфолио**. Доступно для свободного скачивания и развертывания.

### 🏗️ Функционал
*   **Чаты пользователей:** Чаты на 2 и более пользователей.
*   **Реакции и комментарии сообщений**
*   **Отслеживание комментариев:** Отслеживание 500 последних сообщений, на которые пользователь оставил комментарий.
*   **Без открытой регистрации:** Учетные записи пользователей создаются исключительно администратором системы.
*   **Мягкое удаление (Soft Delete):** При удалении сообщений, чатов, реакций пользователями, они не стираются физически из системы. Информация помечается флагом `deleted` в базе данных и сохраняется для обеспечения соответствия применимому законодательству.

#### Описание
Этот репозиторий содержит модульную среду разработки, оптимизированную для безопасного развертывания кода. В проект интегрирован рабочий процесс, построенный вокруг современных стандартов безопасности GitHub.

#### Ключевые Особенности
*   **Безопасный доступ:** Интеграция с точечными токенами доступа (Fine-grained PATs) со строгими правами на запись на уровне репозитория (`Contents: Read and Write`).
*   **Контроль версий:** Полная история Git, чистая гигиена коммитов и управление ветками.
*   **Кроссплатформенность:** Полная совместимость с основными терминалами и современными средами разработки (IDE).

#### Предварительные требования
Для клонирования, отправки (push) или изменения этого репозитория убедитесь, что в вашей учетной записи GitHub настроен точечный персональный токен доступа (Fine-Grained PAT) с разрешениями **Contents: Read and Write**.
